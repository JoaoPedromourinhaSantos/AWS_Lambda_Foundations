## 📚 Conteúdo do Curso

O curso abordou:

- Definir o Lambda e descrever como ele funciona
- Entender os benefícios do Lambda e identificar os casos de uso
- Examinar permissões e segurança da função do Lambda
- Entender práticas recomendadas de gravação das funções do Lambda
- Implantar e testar aplicativos sem servidor

---

## 🚀 Tópicos Principais

- O que é AWS Lambda e como funciona internamente
- Arquitetura orientada a eventos e integração com outros serviços AWS
- Modelos de invocação (síncrona, assíncrona, polling)
- Permissões, funções de execução (IAM) e políticas baseadas em recursos
- Boas práticas de desenvolvimento, monitoramento e otimização
- Deploy e testes de aplicações serverless
